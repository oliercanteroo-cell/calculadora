# Calculadora metálica

Calculadora hecha con HTML, CSS y JavaScript puros.

**Demo en vivo:** https://oliercanteroo-cell.github.io/calculadora/

![Captura de la calculadora](imgcalculadoraMetalica.png)

## Características
- Suma, resta, multiplicación y división con jerarquía de operaciones
- Porcentaje y cambio de signo
- Se ve la operación completa antes de pulsar =
- Soporte de teclado
- Historial guardado en el navegador
- Diseño metálico y sonido al pulsar botones

## Tecnologías
HTML5 · CSS3 · JavaScript (Web Audio API, localStorage)
